# 하니피알(hanipr) 메인 리뉴얼 설계서

- 통과 조건: 공모전 필수 조건 15개 전부 + 넥스트티 SEO 100 / GEO 엔티티 100

## 1. 포지셔닝
- 벤치마킹: adresult.kr 의 설득 흐름(상황별 진입 → 증거 → 숫자 → 후기 → FAQ → CTA)만 차용. 디자인·문구는 차용하지 않음.
- 차별점: 경쟁사는 AI 노출을 "말"로 설명 → 하니피알은 에이전트Q 대시보드로 "보여줌". 한의원 질문(교통사고·추나·다이어트 한약·암요양) 단위 예시.
- 금지 표현: 가장·1위·최고·유일·No.1·국내 최다. 현재 사이트의 "대한민국 1위/No1" 문구 전부 제거.

## 2. 디자인
- 흰 바탕 + 포인트 컬러 1개: 한방 녹색 `#1F7A5C`
  - 이유: "한약재·자연을 떠올리게 하고, 병원 블루와 겹치지 않아 한의원 전문 대행사라는 게 바로 보인다."
- 본문 텍스트는 짙은 회색, 보조 회색 1단계만 사용. 포인트 컬러는 CTA·강조 숫자·그래프에만.
- PC/모바일 반응형 단일 주소.

## 4. 메인 섹션 순서
1. 첫 화면: H1 `SEO·AEO·GEO, 한의원 한방병원 마케팅대행사`(페이지 최대 글씨) + 서브 "SEO·AEO·GEO를 잘하는 대행사" + [무료 AI 노출 진단] CTA ①
2. 원장님 상황별 버튼 4개: 개원 준비 / 대형병원 출신 개원 / 광고 중인데 신환 정체 / 주변 경쟁 한의원 증가 → 해당 상품 페이지로 이동
3. 3대 상품 카드: SEO·AEO·GEO(AI 매거진) / 숏폼 / 마케팅 자동화
4. 에이전트Q 미리보기: AI별 노출 점유율 막대 + 경쟁사 대비 순위 표 ("예시" 표기)
5. 숫자: 17년+ / 전문 인력 70여 명 / 자체 네트워크 플랫폼 6개 (현 사이트 공개 수치만)
6. 원장님 후기 슬라이드 + 카톡·리얼 후기 이미지 m01~m05 (이름·상호 마스킹 유지)
7. 네트워크 사이트 로고 6개(링크): 한방카·우먼닥·생생추나·입원닷컴·산재OK·힐링오아시스
8. FAQ 4~6개 (FAQPage JSON-LD)
9. 영상 갤러리: 썸네일이 좌측으로 무한 흐름(CSS marquee), hover/focus 시 멈춤, 클릭 시 재생. `prefers-reduced-motion` 시 정지
10. 마지막 상담 섹션 + 간단 폼 — CTA ②

고정 장치: 모바일 하단 바(전화·카톡·무료진단), PC 우하단 카톡 버튼. 카톡 채널 미확보 시 전화 연결로 대체.
