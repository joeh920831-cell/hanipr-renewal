# 상담 폼 접수 연결 (구글 시트 + Gmail 알림) — 약 10분

1. sheets.new 로 새 구글 시트 만들기 → 이름: `하니피알 상담 접수`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 지우고 `Code.gs` 내용 전체 붙여넣기 → 맨 위 `NOTIFY_EMAIL` 확인 → 저장(💾)
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. **배포** → 권한 승인(고급 → 안전하지 않은 페이지로 이동 → 허용) → **웹 앱 URL 복사**
6. 복사한 URL을 Claude에게 전달 → `src/form.mjs` 의 `FORM_ENDPOINT` 에 넣고 다시 빌드

접수 내용은 시트의 `Leads` 탭에 한 줄씩 쌓이고, 동시에 알림 메일이 갑니다.
